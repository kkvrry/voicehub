VoiceHub 便携版
===============

启动
  双击 VoiceHub.exe。首次启动会自动打开浏览器，并在右下角托盘常驻。
  关闭浏览器不会停止服务；要退出请右键托盘图标 → 退出。
  Windows 11 首次运行时图标在任务栏的 ^ 折叠区里：点开，把声波图标拖到任务栏。

第一次使用
  在网页的「设置」里填写你要用的合成引擎、语音识别与对话模型的地址和密钥。
  没有配置引擎时，扫描音色、试听等本地功能仍可使用。

数据放在哪
  %LOCALAPPDATA%\voicehub
  里面是 config.json（密钥已用当前 Windows 账户加密）、音色库数据库、
  生成结果与 logs 日志。卸载时删掉这个目录即可彻底清除。

开机自启
  右键托盘图标 → 勾选「开机自启」。程序目录搬家后，下次启动会自动改指新位置。

ffmpeg
  已随包内置 ffmpeg / ffprobe，不需要另外安装。

常见问题
  · 端口被占用：多半是另一个 VoiceHub 还在运行。先退出旧的托盘程序；
    或在命令行执行 VoiceHub.exe --port 17866。
  · 首次运行被 SmartScreen 拦截：程序未做代码签名，选择「更多信息 → 仍要运行」。
  · 启动失败：查看 %LOCALAPPDATA%\voicehub\logs\voicehub.log 与 launcher.log。

把数据放在本目录（可选）
  在快捷方式的目标后面加 --data-dir data，数据就会写进程序目录下的 data 文件夹。
